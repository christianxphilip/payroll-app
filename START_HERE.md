## 🎯 First Steps After Login

1. **Add Employees**
   - Click "Employees" → "Add Employee"
   - Enter employee names
   
2. **Configure Holidays**
   - Click "Holidays" → "Add Holiday"
   - Add regular/special holidays

3. **Upload Schedule**
   - Click "Schedules" → "Upload CSV"
   - Or manually add schedules

4. **Log Timesheets**
   - Click "Timesheets" → "Add Timesheet Log"
   - Enter time in/out
   - System auto-calculates everything!

5. **Generate Report**
   - Click "Payroll Report"
   - Select date range
   - Generate and export

## 🆘 Need Help?

### Common Issues

**Can't start the system?**
```bash
# Make sure Docker is running
docker ps

# Try stopping and restarting
docker-compose down
./start.sh
```

**Can't login?**
- Password is: `admin123`
- Clear browser cache

**Backend not responding?**
```bash
# Check logs
docker-compose logs backend
```
